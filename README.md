# Explainable AI-Based Pediatric Bone Age Prediction

## Project Overview
A deep learning project to predict pediatric bone age from hand and wrist X-ray images using computer vision and Explainable AI.

## Objectives
- Perform exploratory data analysis.
- Preprocess medical X-ray images.
- Develop a baseline CNN model.
- Implement ResNet50 using transfer learning.
- Predict bone age in months using regression.
- Evaluate model performance.
- Implement Grad-CAM for explainability.
- Develop a Streamlit application.

## Dataset
RSNA Pediatric Bone Age Challenge 2017.

Dataset source:
https://www.rsna.org/artificial-intelligence/ai-image-challenge/rsna-pediatric-bone-age-challenge-2017

## Technology Stack
- Python
- PyTorch
- Torchvision
- OpenCV
- NumPy and Pandas
- Matplotlib and Seaborn
- Scikit-learn
- Grad-CAM
- Streamlit

## Models
1. Custom CNN
2. ResNet50 with Transfer Learning

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R2)

## Explainable AI
Grad-CAM will be used to visualise image regions influencing model predictions.

## Deployment
A Streamlit application will provide predictions and visual explanations.
